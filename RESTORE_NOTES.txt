Dabba Direct clean restore pack

Restore location:
  /var/www/dabba-test

Archives contain these top-level folders:
  dabbadesk-v2
  dabba-shared
  ordertest.dabbadirect.com

After extracting, run:

  cd /var/www/dabba-test/dabbadesk-v2
  composer update dabba-direct/intake-tools --with-dependencies
  composer dump-autoload -o
  php artisan optimize:clear

  cd /var/www/dabba-test/ordertest.dabbadirect.com
  composer update dabba-direct/intake-tools --with-dependencies
  composer dump-autoload -o
  php artisan optimize:clear

Shared package path expected by both apps:
  /var/www/dabba-test/dabba-shared/intake-tools

Quick checks:

  cd /var/www/dabba-test/dabbadesk-v2
  composer show dabba-direct/intake-tools -P
  php artisan tinker
  class_exists(\DabbaDirect\CommerceTools\Services\UrlResolverService::class);
  class_exists(\DabbaDirect\IntakeTools\ProductUrlResolver::class);

  cd /var/www/dabba-test/ordertest.dabbadirect.com
  composer show dabba-direct/intake-tools -P
  php artisan tinker
  class_exists(\DabbaDirect\CommerceTools\Services\UrlResolverService::class);

Important architecture notes:
  - CommerceTools is the real implementation namespace.
  - IntakeTools remains only as backwards-compatible adapters for existing CMS code.
  - Old root-level duplicate shared classes were removed.
  - Unknown redirect hosts such as share.google are not treated as retailers.
  - Redirect/share hosts are resolved first, then cleaned, then retailer detection runs.
